curl -fsSL https://raw.githubusercontent.com/Mesh-LLM/browser-extension/main/install.sh | bash

Downloads the latest mesh-llm preview and lets this extension start it. If mesh-llm is already running some other way, the extension still shows it — setup is only needed for Start/Stop.
